# もう寝る 1.2.0

Windows 11 x64用のスリープ・シャットダウンタイマーです。インストールは不要です。

## 使い方

1. `MouNeru.exe`を開きます。
2. 「何分後に」または「時刻を指定」で時間を入力します。
3. 「スリープ」または「シャットダウン」を選び、予約します。

## 予約について

- 予約した時間は変更でき、予約を取り消すこともできます。
- 「今すぐ」は5秒後に実行され、その間は取り消せます。
- アプリを終了すると予約は取り消されます。再起動後には復元されません。
- 保存していない作業やPCの電源設定により、実行できない場合があります。

## 配布ファイルについて

このEXEは署名されていないため、Windowsが警告を表示する場合があります。

`MouNeru.exe.sha256`はEXEを確認するためのチェックサム、`LICENSE`はMITライセンスの文書です。
